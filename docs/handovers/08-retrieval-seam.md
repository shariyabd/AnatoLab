# Handover 08 — The retrieval seam, for Handover 11

**Branch:** `feat/f08-ai-tutor-core` · **Status:** complete · Read before starting F11.

Handover 08's Definition of Done requires documenting exactly where Handover 11 inserts.
This is that document. `docs/handovers/parallel-execution-plan.md` D2 says F11 is the only
lane permitted to touch `AITutorService`, and only at this seam.

---

## 1. One method, one file

```
app/Services/AI/AITutorService.php  →  private function retrieveGrounding()
```

Nothing else in F08 needs to change. Everything downstream — the prompt, `sources[]`, the
source note, the stored message metadata, the API Resource, and the panel that renders
citations — is already written against a **non-empty `list<RetrievedChunk>`** and has tests
that pass with one.

Today the method returns `[]`, and every one of those paths takes its "no sources" branch.

## 2. The insertion

1. Add the collaborator to the constructor:

   ```php
   public function __construct(
       private readonly AIProviderInterface $provider,
       private readonly AnatomyService $anatomy,
       private readonly AIContextBuilder $contextBuilder,
       private readonly PromptBuilder $prompts,
       private readonly AIResponseValidator $validator,
       private readonly RetrievalService $retrieval,   // ← F11
   ) {}
   ```

2. Replace the body of `retrieveGrounding()`:

   ```php
   return $this->retrieval->search(
       query: $question,
       topK: (int) config('ai.retrieval.top_k', 5),
       filters: array_filter([
           ...$context->retrievalFilters(),
           'organ_id' => $organ?->getKey(),
           'structure_id' => $structure?->getKey(),
       ], static fn (mixed $value): bool => $value !== null),
   );
   ```

3. Apply `config('ai.retrieval.min_score')` **inside** `RetrievalService`, not here. That
   keeps this method's empty return meaning "nothing was relevant" rather than "nothing was
   indexed" — the distinction the source note depends on.

`RetrievalService` owns embed-then-search: `VectorStoreInterface::search()` takes a vector,
not a string (`docs/architecture.md` §8.1).

## 3. Why the organ and structure are parameters

`LearningContext` is frozen and its `retrievalFilters()` returns only `education_level`.
`docs/architecture.md` §8.2 also specifies `organ_id` and `structure_id`. They are passed into
the seam as resolved models so the filter set can be assembled without unfreezing a contract.

## 4. What is already built, and must keep working

| Behaviour | Where | After F11 |
|---|---|---|
| `sources[]` in the envelope | `TutorReplyResource` | fills with `{id, title, excerpt}` |
| `sourceNote` — the tutor saying it had no sources | `AITutorService::sourceNoteFor()` | returns `null`; citations are the statement |
| Citation rendering | `resources/js/Components/Tutor/TutorSources.vue` | already renders a non-empty list |
| `metadata.source_ids` on the stored assistant turn | `AITutorService::recordTurn()` | fills with chunk ids |
| Prompt block "Relevant educational sources" | `PromptBuilder::userTurn()` | switches to the formatted-chunk branch |

`sourceNote` is generated by the application, not asked of the model, so "the tutor says when
it had no sources" is a tested server behaviour rather than a hope about instruction-following
(`tests/Feature/AI/GroundingTest.php`). **Do not** replace it with a prompt instruction.

## 5. Embeddings — decide this before you start

`AnthropicProvider::generateEmbeddings()` **throws**. Anthropic publishes no embeddings
endpoint; `config/ai.php` already reflects it, since only the `openai` block carries an
`embedding_model` key.

So an installation running `AI_PROVIDER=anthropic` cannot embed. F11 has to choose one:

- run OpenAI for embeddings and Anthropic for chat (two provider instances), or
- add a dedicated embeddings provider behind the same interface, or
- accept that RAG requires `AI_PROVIDER=openai`.

Failing loudly was chosen over returning zero vectors, which would silently rank every chunk
identically and look like a retrieval-quality problem.

## 6. Things not to touch

- `app/Contracts/**` — frozen.
- `bootstrap/providers.php` and `.env.example` — append `RagServiceProvider` and your keys
  **after** F08's lines; never reorder.
- `config/ai.php` — `vector_stores` and `retrieval` are already stubbed by Handover 01 and
  need no shape change.
