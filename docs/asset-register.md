# Asset Register

**Owner:** Handover 02 (Content lane) · **Last updated:** 2026-09-05
**Release gate:** nothing deploys publicly until §6 is signed.

Every model, texture and illustration that ships must have a row here. The rule is
mechanical, not aspirational: each row carries an **ID**, every entry in
`public/models/manifest.json` carries a `registerId`, and `node scripts/verify-models.mjs`
fails if a manifest entry names an ID this file does not contain. A model without a row
cannot be recorded as shippable.

Never assume open source means redistributable. Code and assets are audited separately —
the audit trail for the licence question itself is `docs/licence-log.md`.

**Status vocabulary**

| Status | Meaning |
|---|---|
| `BLOCKED` | Cannot ship. Rights are absent, unclear, or insufficient |
| `CLEARED` | Licence permits public deployment; attribution string below is final |
| `CANDIDATE` | Under evaluation as a replacement; no rights exercised yet |
| `EXCLUDED` | Deliberately not shipped |

Two non-legal defects are recorded here because they survive any licence outcome:

- **Single-mesh geometry.** Every file is one node, one mesh, one primitive, one material.
  There is no per-structure geometry (`docs/project-context.md` §2.2), so per-structure
  selection, isolation and layer visibility are impossible against these assets. A licence
  grant does not change this.
- **Unverified anatomical accuracy.** These are generative output, not derived from imaging
  or dissection. For a product aimed at 13–18-year-olds that is a content-quality risk.
  **Flagged to F03's owner**, who owns content correctness. Handover 02 does not decide it.

Budget compliance is a solved problem for this geometry — see `scripts/README.md`
§"Measured results". All nine re-encode inside 2 MB and 150k triangles. That measurement
was taken against local copies in a scratch directory for evaluation; **no upstream binary
has been committed to this repository or deployed**, and `.gitignore` excludes
`/public/models/*.glb` regardless.

**DEC-01 / DEC-02 are excluded, not blocked.** 1.6 MB of decoder payload shipped upstream
that nothing referenced — the audited loader configures only `MeshoptDecoder`
(`docs/project-context.md` §2.6). Neither directory exists in this repository, and
`scripts/verify-models.mjs` fails the build if either reappears. Reintroduce a KTX2
transcoder **only** when a loader actually uses it — which is F04's call, at the point it
loads a model whose textures are genuinely KTX2. Both are Apache-2.0 and must ship with
their licence text if reintroduced; upstream vendored them without it.

**DEP-02 caveat.** GSAP's standard licence permits free use including in commercial
products, but it is a bespoke licence, not OSI, and it restricts redistributing GSAP itself.
Read `https://gsap.com/standard-license` and confirm before public deployment. GSAP is used
by the audited viewer for camera easing; if the terms are unacceptable the dependency is
droppable — the easing is replaceable with a few lines of `requestAnimationFrame`.

**DEP-03 is build-time only.** These never reach the client bundle; they run in
`scripts/encode-model.mjs`.

### Recommendation

**NIH 3D's HuBMAP reference-organ set.** It is the only candidate that satisfies all four
constraints at once: plain CC BY with no share-alike, so a publicly deployed competition
entry is unencumbered and our own code stays under whatever licence we choose; native GLB
with named per-structure meshes, which removes the format conversion *and* the segmentation
problem that `docs/project-context.md` §2.2 exists to work around; polycounts already inside
decimation range; and 9/9 coverage across 18 identified entries.

The costs are real and bounded: 18 files harvested individually through an unofficial
endpoint, a per-model licence check that must actually be performed, and a verbatim
per-model attribution string with its own DOI stored against each organ.

**If this is adopted, F04's scope changes from *adapt* to *reimplement*, and F05/F07 gain
real mesh raycasting.** Say so loudly to those lanes rather than letting them discover it —
handover 02 is explicit about this, and `docs/licence-log.md` §4 records why.
